# README

**FlowchartGenerator** — десктопное приложение на C#/WinForms, которое строит блок-схемы алгоритмов по исходному коду **Python**, **C#** и **C++** в соответствии с **ГОСТ 19.701-90** (ИСО 5807-85).

## Возможности

- **Три языка на входе**: Python, C#, C++. Язык выбирается вручную в выпадающем списке тулбара или определяется автоматически по расширению файла при загрузке.
- **Построение блок-схем** с использованием символов по ГОСТ 19.701-90:
  - **Терминатор** — начало/конец программы (овал).
  - **Процесс** — присваивание, объявление с инициализацией, шаг цикла (прямоугольник).
  - **Решение** — `if` / `elif` / `switch` (ромб).
  - **Данные (ввод/вывод)** — `print`, `return`, `Console.WriteLine` (параллелограмм).
  - **Предопределённый процесс** — вызов функции/метода (прямоугольник с двойными стенками).
  - **Граница цикла** — начало и конец `while` / `for` (две половины шестиугольника, пара имеет одно имя).
  - **Соединитель** — точка слияния ветвлений `if/else` (круг с меткой `λN`).
- **Раскладка блоков** — слоевая (BFS), с учётом обратных рёбер циклов; центрирование по строкам.
- **Прямые ортогональные рёбра** между блоками (без кривых), с метками условий («Да» / «Нет») у портов выхода — согласно п. 4.3.1.2 ГОСТа.
- **Наведение мышью**:
  - На **ребро** — оно подсвечивается и по нему «бежит» пунктир в направлении потока.
  - На **блок** — подсвечиваются все инцидентные рёбра: входящие «бегут» к блоку, исходящие — от блока. Дополнительно всплывает **подсказка с названием символа по ГОСТ** (например, «Решение», «Данные (ввод/вывод)»), идентификатором, именем цикла и содержимым.
- **Панорамирование** холста — перетаскиванием мыши.
- **Масштабирование** — колесом мыши (0.15× … 4×), с сохранением точки под курсором.
- **Экспорт в PNG** — всегда в светлой теме, кадрируется по границам блок-схемы.
- **Светлая и тёмная темы** — переключаются одной кнопкой.

## Поддерживаемые конструкции

| Конструкция | Python | C# | C++ |
|---|---|---|---|
| Присваивание | `x = 5` | `int x = 5;` | `int x = 5;` |
| Ветвление | `if / elif / else` | `if / else if / else` | `if / else if / else` |
| Цикл `while` | ✔ | ✔ | ✔ |
| Цикл `for` | `for x in iterable` | `for (init; cond; step)` | `for (init; cond; step)` |
| `do { } while ( )` | — | ✔ (разворачивается в `while`) | ✔ |
| `switch` | — | ✔ (разворачивается в `if/else if`) | ✔ |
| `return` | ✔ | ✔ | ✔ |
| `break` / `continue` | ✔ | ✔ | ✔ |
| Вызов функции/метода | ✔ | ✔ | ✔ |
| `try / catch / finally` | — | ✔ (тело `try` разбирается, обработчики пропускаются) | ✔ |
| Объявления классов, `using`, `#include`, `namespace`, `typedef` | — | пропускаются | пропускаются |

Парсеры анализируют **тело первой функции/метода** (обычно `Main`), пропуская служебный обвес — так блок-схема получается компактной и отражает логику, а не структуру файла.

1. Откройте VS Community → **Файл → Открыть → Папка** и выберите папку с проектом.
2. Убедитесь, что Solution Explorer показывает `WindowsFormsApp1.csproj`.
3. Нажмите **F5** (запуск с отладкой) или **Ctrl+F5** (запуск без отладки).

```bash

dotnet run
```

## Использование

1. **Выберите язык** в выпадающем списке тулбара (`Python`, `C#`, `C++`) — в редакторе появится соответствующий пример кода.
2. Отредактируйте код или нажмите **«Загрузить файл»** — расширение определит язык автоматически.
3. Нажмите **«Сгенерировать»** — блок-схема построится и автоматически впишется в холст.
4. **Наведите** курсор на блок — увидите подсказку с названием символа по ГОСТ и «бегущие» рёбра.
5. **Перетаскивайте** холст мышью, **масштабируйте** колесом.
6. **«Сохранить PNG»** — экспорт схемы в растровый файл.
7. **«Тёмная тема» / «Светлая тема»** — переключение оформления.

### Пример

Python:

```python
x = 10
y = 20
if x > y:
    print("x больше")
    result = x
else:
    print("y больше")
    result = y

i = 0
while i < 5:
    print(i)
    i = i + 1

print("готово")
```

Приведёт к блок-схеме с ромбом (`x > y`), ветками «Да» / «Нет», двумя параллелограммами ввода-вывода, а также циклом `while i < 5` с обратным ребром и меткой «Нет».

## Ограничения

- Парсеры работают **эвристически** и ориентированы на учебный/линейный код. Сложные конструкции (лямбды, генераторы, шаблоны C++, множественное наследование) не раскрываются.
- `switch` в C# и C++ **разворачивается в цепочку `if/else if`**, а не в отдельный символ «Вариант» — сознательное упрощение.
- `do { } while` разворачивается в обычный `while` (условие выхода рисуется в начале).
- `try/catch/finally` — в схему попадает только содержимое `try`.
- Функции внутри функций (вложенные) разворачиваются в общий поток, а не в отдельные подпрограммы.
